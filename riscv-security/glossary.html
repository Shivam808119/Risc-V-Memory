Security glossary A–Z

Plain-English definitions for terms used throughout the security course, with official references for deeper study.

Use this page whenever a term feels unfamiliar. Definitions are intentionally practical; consult the linked specification for exact architectural wording.

Access controlA rule deciding whether an actor may perform an operation on a resource.
Attack surfaceInterfaces and behaviors an attacker may influence.
AttestationEvidence about a device's identity or measured state, usually rooted in cryptographic keys.
Bus masterA component that can initiate memory/interconnect transactions independently of CPU instructions.
ConfidentialityPreventing unauthorized disclosure of information.
Constant-timeImplementation strategy that avoids secret-dependent timing behavior under a defined threat model.
CSRControl and Status Register; architectural control/state register with privilege restrictions.
DMADirect Memory Access; a device transfers data to/from memory without the CPU issuing every transfer.
ECCError-correcting code; can detect and sometimes correct selected data corruption patterns.
Fault injectionDeliberately disturbing operation (e.g. clock/voltage/EM) to induce erroneous behavior.
Firewall (bus)Hardware access-control logic on an interconnect that restricts initiators, addresses or operations.
IOMMUInput/output memory management unit that translates and restricts device DMA addresses.
IntegrityProtection against unauthorized modification, with detection or prevention depending on mechanism.
MMUMemory Management Unit; translates virtual addresses and enforces page permissions.
PMPPhysical Memory Protection; RISC-V mechanism for region-based physical access permissions, when implemented.
Privilege modeArchitectural execution level, such as M, S or U, with different authority.
Root of trustSmallest trusted component on which later verification or security decisions depend.
Secure bootBoot process that verifies software before trusting or executing it.
Side channelObservable indirect signal (timing, power, cache behavior) that can reveal information.
SmepmpRISC-V extension that enhances PMP, including stronger control of M-mode access to protected regions.
SoCSystem-on-chip: CPU, memory, interconnect, peripherals and control logic integrated together.
SpeculationExecuting or issuing work before it is certain that the work will be architecturally needed.
Threat modelExplicit statement of assets, attacker abilities, goals and assumptions.
TLBTranslation Lookaside Buffer; cache of virtual-to-physical translations and permissions.
TOCTOUTime-of-check to time-of-use: a checked value changes before the later operation uses it.
Trust boundaryBoundary between components with different trust assumptions or authority.
U/S/M modeUser, Supervisor and Machine privilege modes in the RISC-V privileged architecture.
W^XPolicy that memory should not be writable and executable at the same time.
