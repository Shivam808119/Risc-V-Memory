CORE SECURITY PROFILES

Compare the ten cores

Ten RISC-V core families, what they are, what security areas deserve attention, and how to verify capabilities without making unsupported assumptions.

Use these profiles to plan a review. The descriptions are orientation, not proof of security properties. Each page lists what to inspect and what evidence to collect.

Research rule: a core profile cannot certify an SoC. Always verify the exact release, generated configuration, wrapper, bus fabric, boot firmware and debug policy.

Recommended order

  1. PicoRV32: understand a simple request interface and why a bus is not a firewall.
  2. Ibex: study explicit security-oriented implementation options.
  3. CV32E40P: practice following interfaces and fault paths.
  4. Rocket Core and VexRiscv: understand configuration-generated capabilities.
  5. SonicBOOM: deepen speculative execution and side-channel analysis.
  6. Then SERV, SweRV EH1, VEGA and Shakti using the same evidence checklist.
Learning resource, not a certification or security audit. Always verify the exact RTL revision, configuration, firmware and SoC integration. Sources and scope.
