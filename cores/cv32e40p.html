CV32E40P memory system profile

4-stage in-order 32-bit CORE-V processor. Official docs describe OBI-compliant instruction-fetch and load/store data interfaces. Its prefetch machinery must not automatically be called a conventional cache.

How to read this profile: verified general characteristics are separated from questions you must confirm for your exact build. Core-family capability is not proof that your configuration enables a feature.

What it is

CV32E40P is a 4-stage, in-order 32-bit CORE-V processor. Its official user manual documents OBI-compliant instruction-fetch and load/store data interfaces. It also has instruction-fetch prefetch machinery, which should not automatically be described as a conventional cache.

OBI in plain English

OBI (Open Bus Interface) describes a request/response protocol. The request side presents a command/address; grant indicates acceptance; response-valid indicates response data/status is available. Address stability and precise handshake rules matter because the core must not change a request after the receiving system has accepted it.

Instruction prefetch FIFO vs cache

A FIFO (first-in, first-out queue) can hold instructions fetched ahead of execution. It smooths short timing gaps and allows the fetch stage to stay ahead. A conventional cache stores tagged lines and can satisfy later accesses to the same block after branches/loops. A prefetch FIFO and an instruction cache solve overlapping but different problems.

Data-side LSU

The load/store unit forms memory commands and handles response timing. Investigate how byte enables, alignment, outstanding transactions and exceptions are handled in the selected version. Follow the OBI port into the surrounding system to discover whether it reaches SRAM directly or passes through a cache/adapter.

What to inspect in the manual/RTL

  • Instruction Fetch chapter and LSU chapter.
  • Core integration template and top-level ports.
  • Configuration parameters and optional FPU/APU integration.
  • OBI request/grant/response timing.
  • Misaligned instruction fetch handling and access error paths.

Source

Official CV32E40P user manual describes the OBI interfaces and explains the core's structure. Verify details against the version of the manual that matches your RTL.
