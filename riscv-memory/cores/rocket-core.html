CORE PROFILE

Rocket Core memory system profile

Configurable in-order RISC-V core in Rocket Chip. Generated systems often use TileLink and configurable cache/TLB structures. Values belong to a particular generated configuration, not every Rocket instance.

How to read this profile: verified general characteristics are separated from questions you must confirm for your exact build. Core-family capability is not proof that your configuration enables a feature.

What it is

Rocket Core is an in-order RISC-V core used within the configurable Rocket Chip generator ecosystem. In a generated SoC, memory behavior depends on the chosen Rocket parameters and the system constructed around the core.

TileLink and the system around Rocket

Rocket Chip commonly uses TileLink for on-chip interconnect. TileLink connects components such as processor tiles, caches, memory controllers and peripherals. It is not the RISC-V ISA and it is not a cache by itself. It is a family of transaction protocols used to build the system.

Configuration-dependent memory features

Cache capacities/ways, TLB parameters, optional extensions, outer cache/interconnect, memory map and DRAM controller are determined by the generated configuration. “Rocket has an L1 cache” is incomplete unless the exact build and cache parameters are specified.

How to investigate a generated Rocket system

  1. Find the configuration class or generator parameters used by the build.
  2. Identify the Rocket tile, instruction/data cache parameters and TLB settings.
  3. Trace the tile's TileLink ports into the crossbar/fragmenter/width adapter and memory subsystem.
  4. Identify the physical memory map and whether the system has an outer/shared cache.
  5. Inspect coherence agents and manager capabilities in the chosen interconnect.

Why it matters

Rocket is a useful bridge between an individual core and a full SoC. It teaches that caches, TLBs, bus widths, coherence and address maps are generated as a coordinated system rather than inferred from a CPU name alone.

Terms to know

GeneratorCode that emits a configured hardware design.
TileA processor subsystem, often including the core and nearby cache/interface logic.
TileLink managerA component that responds to TileLink requests.
Width adapterLogic that adapts transaction data width between components.
Coherence agentLogic that participates in maintaining consistent cache copies.
