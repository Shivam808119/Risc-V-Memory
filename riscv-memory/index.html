RISC-V MEMORY LAB

RISC-V memory systems, explained deeply

A guided, beginner-friendly course on how instruction and data access work in ten real RISC-V core families.

Understand memory by following what the processor actually does.

This site starts by introducing the ten cores, then builds the memory concepts from first principles. Every lesson explains what a term means, why the hardware exists, what it costs, and how to look for it in RTL or documentation.

Important distinction: RISC-V is an instruction-set architecture (ISA), not a single CPU design. A core implements instructions; a SoC connects that core to RAM, ROM/flash, caches, peripherals and interconnect. A feature mentioned in a family manual is not guaranteed in every configuration.

How to use this site

  1. Read a lesson in order. Keep the glossary boxes open when a word is new.
  2. After each concept, open the relevant core profile and ask whether the feature is in the core, the generated configuration, or the SoC around it.
  3. Follow official source links. Search RTL for the signals and modules named in the profile.
  4. Record the repository commit, configuration file, and evidence for every technical claim.
Not all ten cores have the same kind of memory system. Some expose a simple external request/response port; others can be configured with caches, translation, speculative load/store machinery or coherent interconnects. Do not compare them as if each had a fixed identical L1/L2/DRAM stack.
