Memory hierarchy and locality

Caches exist because small, fast storage is expensive per bit and large storage is slower. Real programs repeatedly use nearby data and instructions; locality makes a small fast copy useful.

Hierarchy

Registers
tiny, fastest↕L1 cache / scratchpad↕L2 / shared cache↕Main memory↕Persistent storage

This is a conceptual hierarchy, not a promise that all ten cores have all these levels. A small embedded core may connect directly to on-chip SRAM or external memory. An application processor may have several caches, TLBs and a DRAM subsystem.

Why not make all memory as fast as registers?

Fast storage uses more silicon area and energy per bit, and it is harder to scale to large capacities. A hierarchy uses a small amount of fast storage to serve common accesses and a larger, slower level for the rest.

The two kinds of locality

Temporal locality

If a location was used recently, it may be used again soon. Example: a loop counter, stack variable, or repeatedly accessed object.

Spatial locality

If one address is used, nearby addresses may be used soon. Example: walking through an array from element 0 to element N-1.

There is also sequential instruction locality: programs often execute nearby instruction addresses unless a branch changes control flow.

What is a cache line?

A cache normally moves data in fixed-size chunks called cache lines or blocks, not one byte at a time. If a line is 64 bytes, reading one byte can bring in that byte plus its neighbors. This is useful for arrays, but can waste bandwidth if the neighbors are never used.

When locality is poor

Random pointer chasing may have weak spatial locality and a dependency chain that prevents overlap. A working set much larger than cache capacity can cause repeated misses. Two addresses mapping to the same limited cache set can evict each other even if the total cache is not full.

Working set: the set of instructions/data a program actively reuses during a period. If it fits in a fast level, accesses can be quick; if not, misses may rise.
